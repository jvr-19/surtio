# Contribuir a Surtio

Antes de abrir un cambio grande, explica el problema y la propuesta en una issue. Para un fallo, incluye los pasos para reproducirlo, el resultado esperado, versión de Android y versión de Surtio. Oculta ubicación precisa y cualquier dato personal en las capturas.

Mantén los cambios centrados en un problema y utiliza los estilos y componentes existentes. La interfaz principal está en español. Evita introducir datos simulados en flujos que muestran precios reales.

Ejecuta formato, análisis y pruebas indicados en el README antes de enviar una pull request. Añade una prueba cuando corrijas un comportamiento que pueda volver a fallar. Si cambias la interfaz, acompaña el cambio de capturas y revisa tamaños de texto grandes y pantallas estrechas.

No incluyas claves de firma, contraseñas, archivos `key.properties` ni credenciales. Para informar de un problema de seguridad de manera privada, escribe a support@jvrlabs.es.
