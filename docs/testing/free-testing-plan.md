# Plan de prueba gratuita

La beta aún no está activa. Las inscripciones de interés no equivalen a participar en una prueba de Google Play.

1. Completar la configuración y publicar una versión instalable en el canal cerrado.
2. Compartir la invitación con voluntarios reales que dispongan de Android.
3. Usar tester-guide.md para recoger fallos y comentarios privados.
4. Verificar las inscripciones y los plazos que exija Play Console.
5. Corregir incidencias y documentar las pruebas antes de solicitar producción.

No solicitar contraseñas, compras ni reseñas públicas. No prometer intercambios de pruebas que no se puedan cumplir.

Requisitos oficiales: https://support.google.com/googleplay/android-developer/answer/14151465?hl=es
